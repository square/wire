RpcStatus

class RpcStatus(val code: Int = 0, val message: String = "", details: List<AnyMessage> = emptyList(), unknownFields: ByteString = ByteString.EMPTY) : Message<RpcStatus, Nothing>

Wire implementation of google.rpc.Status, the gRPC error model.

gRPC servers send this message, encoded and base64'd, in the grpc-status-details-bin trailer. Its details carry typed error payloads such as google.rpc.ErrorInfo; use AnyMessage.unpack to read them. Fields of type google.rpc.Status generated by Wire are typed RpcStatus.

This class is the Kotlin output of Wire for google/rpc/status.proto, renamed so that it can't conflict with com.google.rpc.Status from proto-google-common-protos. The type URL is unchanged.

The Status type defines a logical error model that is suitable for different programming environments, including REST APIs and RPC APIs. It is used by \[gRPC\](https://github.com/grpc). Each Status message contains three pieces of data: error code, error message, and error details.

You can find out more about this error model and how to work with it in the \[API Design Guide\](https://cloud.google.com/apis/design/errors).
