callTimeout

fun callTimeout(timeout: Long, unit: TimeUnit): GrpcClient.Builder

Sets the default timeout of each call that this client makes. Like a gRPC deadline, the timeout starts when the call executes, and it covers the full lifetime of the call. For a streaming call, this includes all the messages, so configure a sufficiently long timeout for long-running streams.

The client sends the timeout to the server in the grpc-timeout header, and it also enforces the timeout itself. An expired call fails with a GrpcException that has GrpcStatus.DEADLINE_EXCEEDED.

A call can change this value before it executes with GrpcCall.timeout or GrpcStreamingCall.timeout. Use timeout.clearTimeout() to remove it from one call.

This is different from OkHttpClient.Builder.callTimeout, which stops when a streaming call receives its response headers.

Set this to 0 for no timeout. This is 0 by default.
